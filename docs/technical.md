# 技术说明

版本 1.0.0。实际使用的 CoolProp 版本是 6.6.0。运行时写入 `result.json` 的 `environment.coolprop_version` 从已安装的 CoolProp 读取，不在结果里手写死。

## 结构

计算内核在 `evapcond/`，不导入 PySide6。CoolProp 只在 `evapcond/properties/coolprop_backend.py` 导入。界面只调用 `design.run`、`rating.run` 和 `io_json`。

内部单位是 SI：W、Pa、K、kg、m、J/kg。kW、°C、kPa、mm 只在 `io_json` 和界面换算。

## 物性

| 量 | 来源 |
|---|---|
| 制冷剂、水 | CoolProp `PropsSI`，HEOS |
| 水表面张力 | `PropsSI` 的 `I`，IAPWS 2014 |
| 湿空气 | `HAPropsSI`，ASHRAE RP-1485 |
| R404A、R507A | 伪纯质 `HEOS::R404A`、`HEOS::R507A` |

饱和温度范围 −40～+60 °C。湿空气干球 5～50 °C，含湿量 0～该干球下的饱和含湿量。水 5～60 °C。越界抛出 `OutOfRangeError`。

R744 在冷凝温度高于临界温度减 1 K 时停止，消息为「R744 在该冷凝温度下不适用蒸发式冷凝」。

单相 `(T, p)` 距饱和压力过近时，CoolProp 会失败。制冷剂侧在 `|T − T_sat| ≤ 10^{-4}` K 时改用该压力下的饱和相物性。

## 控制容积

空气自下而上，喷淋水自上而下，制冷剂从顶排蛇形流到最底排。每排分段数 `n_L = ceil(N_cv_target / N_r)`，默认 `N_cv_target = 40`，不得小于 20。

外表面积 `dA` 上：

- 显热 `dQ_s = h_c dA (T_w − T_a)`
- 蒸发 `dm_ev = h_m dA (w_s(T_w) − w_a)`，`h_m` 的单位是 kg/(m²·s)
- 潜热 `dQ_l = dm_ev h_fg(T_w)`
- 干空气：`ṁ_a dw_a = dm_ev`
- 干空气焓：`ṁ_a di_a = dQ_s + dm_ev i_g(T_w)`
- 空气温度由 `(i_a, w_a, p_atm)` 反算，不用 `ṁ_a c_p,a dT_a = dQ_s + dQ_l`
- 水膜：`ṁ_w c_pw dT_w = dQ_ref − dQ_s − dQ_l`，`dṁ_w = −dm_ev`
- 制冷剂到水膜：`dQ_ref = (T_ref − T_w) / (R_ref + R_wall + R_film)`
- 制冷剂：`ṁ_c dh_ref = −dQ_ref`

`h_m = h_c / (c_p,a Le_f)`。默认 `Le_f` 是 Bosnjaković 因子，不再另取 2/3 次方。`w_s = w_a` 时 `Le_f → 0.865^{2/3} ≈ 0.908`。可在输入里把 `Le_f` 覆盖为 1。

顶排喷淋水温等于底排出口水膜的质量加权温度。每个控制容积的水膜温度取该段能量平衡的出口温度，并在同一温度上计算热流。

当地压力每次更新饱和温度。区段按当地焓与当地饱和焓划分。

收敛必须同时满足：换热量相对变化 `< 1e-4`，各段水膜温度变化 `< 1e-3` K，各段空气焓变化 `< 1e-2` kJ/kg。最多 500 次。超出则抛出 `ConvergenceError`，并附三项残差。

默认 40 个控制容积目标在 `tests/test_solver.py` 的 3 个 R134a 工况上，分段数加倍后换热量变化小于 0.5%，因此没有提高默认分段数。测试同时检查能量残差 `< 1e-6 Q` 和水量残差 `< 1e-9` kg/s。

## 关联式

确认过的公式、系数和范围以 `docs/correlations.md` 为准。这里只记录程序里实际使用的形式。

管外空气对流和水膜对流都用 Mizushina 等 (1967)，分开调用：

`h = 2102.9 (Γ_m / d_o)^{1/3}`

管径只接受 12.7、19.05、40 mm。`0.195 < Γ_m/d_o < 5.556` kg/(m²·s)。`Γ_m = Γ d_o / S_T`。结果诊断包含补充二规定的说明句。

管内冷凝用补充二写出的 Shah 式，文献标签为 Shah (2009)，不含 2009 年粘度修正：

`h_TP = h_Lo [(1−x)^{0.8} + 3.8 x^{0.76} (1−x)^{0.04} / p_r^{0.38}]`

`h_Lo = 0.023 (G D / μ_l)^{0.8} Pr_l^{0.4} k_l / D`

范围按补充二：液相雷诺数 100–63000，液相普朗特数 1–13。`Re_GT ≤ 35000` 时仍计算并写警告。

单相用 Gnielinski (1976) 公开转写。`Re < 2300` 或 `Re > 5×10^6`，以及普朗特数不在 0.5–2000，抛出越界。`2300 ≤ Re < 3000` 时计算并警告。`x = 1` 的饱和蒸气用这条单相式。

两相摩擦是 Friedel (1979) 乘子加 Blasius 摩擦系数，不是 Friedel 原文摩擦系数。展开式见 `docs/PLAN.md`。干度 0 和 1 退化为对应单相梯度。加速压降 `Δp_acc = G² (v_out − v_in)`，`v = x/ρ_g + (1−x)/ρ_l`。

干管束欧拉数是 Zukauskas 与 Ulinskas 的逆幂级数，系数表在 `docs/correlations.md` 补充四。`k_1 = 1`。`N_r < 10` 时 `C_2 = 1 − 0.45 exp(−N_r/3)`，否则为 1。公共雷诺数端点归入较高雷诺数行。`a = 2.0` 且约 `10^4 ≤ Re_max ≲ 2.36×10^4` 时欧拉数非正，抛出越界，不返回负压降。

湿压降：

`Δp_wet = Δp_dry (1 + 0.5 (Γ_m/d_o) / Γ_ref)`

`Γ_ref = 2.8755` kg/(m²·s)。结果标记 `estimated_wet_correction`。

管路用 Colebrook–White 的 Darcy `λ`。Swamee–Jain 只作初值，`|Δλ| < 10^{-8}`。

板式和低翅片调用即 `UnconfirmedCorrelationError`。本期只算 `surface_type = tube_plain`。

## 热阻与 K

`T*_a` 是饱和空气焓等于当地 `i_a` 时的温度。

- `R_ref = 1 / (h_ref A_i)`
- `R_wall = ln(d_o/d_i) / (2 π k_w dL)`
- `R_out,eq = (T_wo − T*_a) / dQ_ref`

占比 `share_x = Σ (ΔT_x,k q_k) / Σ (ΔT_total,k q_k)`。`K = Q / Σ [A_o,k (T_ref,k − T*_a,k)]`，基准是管外表面积。

## 辅机与设计

迎风面积 `N_t S_T L`。风量 `v_f` 乘迎风面积。风机全压是湿管束压降加上 `(ζ_de + ζ_lv + ζ_st) ρ_a v_f² / 2`。管束和附件用进口湿空气的密度、粘度。

喷淋水量 `Γ · 2 · N_t · L`。水泵扬程是喷嘴压力头、提升高度、沿程阻力和局部阻力。水泵物性用求解得到的循环喷淋水温，压力取进口空气压力。轴功率是有效功率除以效率。

补水量 = 蒸发量 + 排污量 + 风吹损失。蒸发量 `ṁ_a (w_out − w_in)`。排污量 `蒸发量 / (N_cyc − 1)`。风吹损失是风吹损失率乘喷淋水量。

设计总流量 `m_ref = Q_k / (h_in − h_out)`。对每个候选求单回路流量 `m_c`，使出口达到目标过冷度；默认过冷度为 0 时，出口焓等于当地压力下的饱和液焓。`N_t = ceil(m_ref / m_c)`，再以 `m_ref / N_t` 校核，要求 `Q ≥ Q_k`。

默认搜索是补充三的 2268 点粗网格，再在最优点附近细化，细化点不超过 200。最优落在管排 4 或 28、或管长 2 m 或 6 m 时，按补充四外扩后再细化。报告包含「非全局穷举……exhaustive 模式」那一句。输入里如果写明了更小的候选列表，就只算这些列表，不再外扩。

目标是总传热面积最小；面积相同时取风机与水泵轴功率之和较小者。

## 已知限制

25 mm 和 32 mm 不在 Mizushina 的三个管径里，进入该关联式时会越界。迎面风速或管排使出口含湿量超过饱和时，求解器抛出越界，不把含湿量截断到饱和。这些候选不会被当成可行设计。
